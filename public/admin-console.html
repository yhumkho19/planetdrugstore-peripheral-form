Peripheral Item List

ℹ️ How this works

Fill in the Venue/Location and Event Type below, and edit the peripheral items for this specific form (Qty is the starting quantity per item), then click "Update Peripheral Form / Generate Control No." — this saves the list AND generates a new Control No. in one go, with all of this attached to it. Give that number to whoever will fill it up; their dashboard will open with the Venue, Event Type, and item list already filled in. Numbers generated earlier keep whatever was set when they were generated, even if you edit again here later.

🧩 Grouping multiple pieces in one row

Wrap each piece in brackets separated by commas — e.g. [ LAPTOP ] , [ CHARGER ] , [ BAG ] — and give Default Qty in the same order separated by "/" — e.g. 2 / 2 / 2. For a single-piece row, you can just write [ ITEM NAME ] X2 with a matching Default Qty of 2.

🔒 Editing existing rows

Existing items are locked by default so they can't be changed by accident — click ✏️ beside a row to unlock just that row and edit it, or click ↺ Restore Default Items to bring back the built-in bracketed list in one click (still needs "Update Peripheral Form / Generate Control No." below to actually save it).
